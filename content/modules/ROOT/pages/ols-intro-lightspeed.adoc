= Introduction to OpenShift Lightspeed
:navtitle: Introduction to OpenShift Lightspeed

In the previous section, you used GitOps to deploy and manage applications across your managed clusters. Now that you have workloads running across your fleet, a natural question arises: how do you quickly check on the state of those resources without logging into each cluster individually?

As the number of managed clusters grows, so does the cognitive load on platform engineers. Constructing manual search queries and sifting through scattered cluster outputs to answer fleet-wide questions can be time-consuming, especially during critical incidents. What if you could ask your fleet a question in natural language and get an immediate answer?

This is where OpenShift Lightspeed and the MCP Server for Red Hat Advanced Cluster Management come in.

NOTE: The Model Context Protocol (MCP) is an open standard that bridges AI models and external data sources. It allows an AI assistant to discover and interact with tools exposed by external services, without requiring custom integrations for each one.

This module will walk you through the OpenShift Lightspeed integration with RHACM. At the end of this module, you'll have deployed the MCP Server for Red Hat Advanced Cluster Management, connected it to your OpenShift Lightspeed instance and used natural language to query resources across your managed clusters.

== Concepts & Architecture

OpenShift Lightspeed is Red Hat's AI-powered assistant built into the OpenShift Console. This operator helps administrators interact with their clusters using natural language, answering questions, explaining resources, and guiding troubleshooting. OpenShift Lightspeed works out of the box for single-cluster queries, leveraging its built-in MCP tools to read resources directly from the cluster it runs on.

However, in a multicluster environment managed by RHACM, administrators often need to query resources running across their entire fleet, not just the hub cluster. This is where the MCP Server for Red Hat Advanced Cluster Management extends OpenShift Lightspeed's reach. This MCP server provides a single tool (_find_resources_) that provides access to the ACM Search database. The MCP server translates natural language prompts into structured search queries against the RHACM Search API, enabling OpenShift Lightspeed to query resources across all your managed clusters from a single chat interface.

NOTE: The MCP Server for Red Hat Advanced Cluster Management is currently a Technology Preview feature. For more information, refer to the https://github.com/stolostron/search-mcp-server[MCP server repository].

=== How it works

Here's the flow when you ask a fleet-wide question:

. You type a natural language question in the OpenShift Lightspeed chat (e.g., _"Are there any failing pods in my production cluster?"_).
. The LLM decides to make use of the _find_resources_ tool provided by the ACM's MCP. 
. OpenShift Lightspeed sends the query to the MCP server.
. The MCP server translates it into an RHACM Search API query and executes it against the hub cluster.
. The structured results are returned to the LLM for analysis and presented back to you as a conversational response.

With this flow, the entire fleet becomes queryable through a single conversational interface.
