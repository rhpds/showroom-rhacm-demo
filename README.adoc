= RHACM Demo

This repository contains the Showroom content for the Red Hat Advanced Cluster Management for Kubernetes (RHACM) demo available through the Red Hat Demo Platform.

_Contents:_

- *Cluster Lifecycle Management:* Provision and manage clusters from a centralized hub.
- *Virtualization Lifecycle:* Manage virtual machines and virtualization workloads across clusters.
- *Governance:* Apply policies consistently across managed clusters and monitor configuration drift/compliance.
- *Multicluster Observability:* Centralize monitoring, metrics, alerts, and insights across clusters.
- *Application Lifecycle Management:* Deploy and manage applications across multiple clusters.
- *OpenShift Lightspeed:* Query fleet-wide resources using natural language with the MCP server for Red Hat Advanced Cluster Management.
- *Business Continuity:* Demonstrate disaster recovery and resilience across clusters.

## Demo Overview

The RHACM demo showcases how Red Hat Advanced Cluster Management provides a centralized
management plane for OpenShift clusters and workloads across hybrid cloud environments.

The demo walks through the main capabilities of RHACM, from cluster provisioning and
governance to application management, observability, virtualization, AI-powered fleet queries with OpenShift Lightspeed, and business continuity.
